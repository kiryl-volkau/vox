# Vox plugin icon assets

Files:
- pluginIcon.svg — primary vector icon
- pluginIcon_dark.svg — dark-theme variant
- pluginIcon_40.png / 80 / 128 / 256 — raster exports when available

For a JetBrains plugin, the SVG files are the preferred project assets because they remain crisp at IDE scaling factors.

Suggested placement:
src/main/resources/META-INF/pluginIcon.svg
src/main/resources/META-INF/pluginIcon_dark.svg
